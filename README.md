# Fullstack Приложение «Заметки» (Дипломный проект)

Веб-приложение для создания, редактирования и поиска заметок с поддержкой Markdown, пагинации и выгрузки в PDF.

## 🛠 Технологический стек
- **Frontend**: Svelte, UIkit (CSS-фреймворк)
- **Backend**: Node.js, Express.js
- **База данных**: PostgreSQL (Развернута в облаке Neon)
- **ORM / Конструктор запросов**: Knex.js
- **Генерация документов**: PDFKit

## 🚀 Основной функционал
- Авторизация пользователей и защита сессий через подписанные Cookie (`cookie-parser`).
- Полноценный CRUD заметок с поддержкой Markdown-разметки (`marked`).
- Автоматический онбординг: генерация приветственной заметки при регистрации.
- Живой регистронезависимый поиск, работающий строго на стороне СУБД через оператор `ILIKE`.
- Оптимизация поиска на фронтенде с помощью паттерна `Debounce` (защита от спама запросами).
- Постраничный вывод записей (пагинация порциями по 10 штук) через SQL-лимиты и смещения (`LIMIT/OFFSET`).
- Система архивации заметок и функция быстрой очистки архива одной кнопкой.
- Скачивание заметок в формате PDF транзитом из оперативной памяти сервера без засорения диска (`doc.pipe`). Поддерживает кириллицу и кликабельные ссылки.

## 💻 Локальный запуск

1. Установите зависимости проекта:
   ```bash
   npm install
   ```

2. Создайте файл `.env` в корне проекта на основе образца `env-sample` и укажите доступы к вашей БД PostgreSQL:
   ```env
   DATABASE_URL="postgresql://username:password@host/neondb?sslmode=require"
   COOKIE_SECRET="ваш_секретный_ключ_кук"
   PORT=3000
   ```

3. Накатите структуру таблиц через миграции Knex:
   ```bash
   npx knex migrate:latest
   ```

4. Запустите сервер в режиме разработки:
   ```bash
   npm start
   ```
   Приложение будет доступно по адресу: `http://localhost:3000`
