# Добро пожаловать! 👋      
> Инструкция по применению

Привет! Это твоя первая автоматическая заметка. Она написана с использованием разметки **Markdown**, чтобы показать возможности приложения.

## Можно создавать заголовок 🚀

И форматировать текст  на  **жирный** или *курсив*.

🎓 **Есть возможность создавать списки:**

**ненумерованый**
* Елемент 1
* Елемент 2
* Елемент 3

**нумерованый**:
1. Елемент 1
2. Елемент 2
3. Елемент 3

💾 **Сохранять ссылки**

[милый котик](https://encrypted-tbn0.gstatic.com/images?q=tbn:ANd9GcRU4JeVL4kd6I1VBC0gDJvVtw5RH9tJcWXsICH2ibO6DfQcQ9GSCc_A1uMH&s=10)

🐱 **Даже сохранять изображения**

![ссылка на изображение](https://encrypted-tbn0.gstatic.com/images?q=tbn:ANd9GcTVAG9UsMy2uLyh8bRUPS99lIihQ3VWTLTsDMbxdlJJzR4N7fBdPJVjIBdB&s=10)


📝 **Отмечать с помощью "X" выполненные дела:**
- [X] создать заметку
- [ ] редактировать заметку
- [ ] сохранить заметку

🗒️ **Также есть различные варианты для просмотра заметок:**
* Глаз - режим просмотра вида заметки
* Книга - режим сравнения
* X-развернуть заметку
* ? - ознакомиться с допольнительной информацией

📦 Если заметка уже не нужна, можно добавить ее в архив, нажав соответсвующую кнопку. Есть возможность просмотреть архивные записи, нажав на сортировку по времени и выбрав "архив".

Запись из архива можно востановить или удалить. ***Внимание: заметка удаляется навсегда!***
